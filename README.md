# Chronicon — dziennik hardcore

Repozytorium służy jako notatnik naszej wspólnej rozgrywki w **Chronicon**.

## Zasady rozgrywki

- Gramy postaciami **po kolei w trybie Hardcore**.
- Śmierć postaci jest ostateczna — po zgonie przechodzimy do następnej postaci.
- Nie kopiujemy gotowych buildów 1:1; rozwijamy postacie wspólnie na podstawie aktualnego lootu, statystyk i drzewka umiejętności.
- Decyzje dotyczące ekwipunku, punktów, gemów i aktywnych umiejętności zapisujemy tutaj, żeby zachować ciągłość między sesjami.

## Aktualna postać

## Co zapisujemy dalej

Przy kolejnych sesjach dopisujemy:

- aktualny poziom postaci,
- wybraną specjalizację i główne drzewko,
- przypisanie aktywnych umiejętności do pada,
- najważniejsze statystyki i problemy buildu,
- kluczowe przedmioty, sety i gemy,
- ważne wybory w trialach i na mapach,
- śmierć postaci i start następnej.
